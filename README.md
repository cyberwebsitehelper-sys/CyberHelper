# Frontend/Backend

## Description

This repository contains the frontend and backend codebase for the NantuDa2ndWebsite project. It is built using modern web technologies including React and Node.js.

## Prerequisites

Before you begin, ensure you have the following installed on your local machine:

- [Node.js](https://nodejs.org/) (v18.x or v22.x recommended)
- [pnpm](https://pnpm.io/) (Strictly used as the package manager for this project)

## Installation

1. Clone the repository or navigate to the project directory:
   ```bash
   cd e:\ProjectFolder\NantuDa2ndWebsite\NantuDa2ndWeb\FrontendBackend
   ```

2. Install all required dependencies using `pnpm`:
   ```bash
   pnpm install
   ```

## Available Scripts

In the project directory, you can run the following commands:

### `pnpm dev`
Runs the app in development mode.
Open http://localhost:3000 (or the port specified in your console) to view it in the browser. The page will reload if you make edits.

### `pnpm build`
Builds the app for production. It correctly bundles React in production mode and optimizes the build for the best performance.

### `pnpm start`
Starts the application in production mode using the previously built artifacts.

### `pnpm test`
Launches the test runner to execute your suite of unit and integration tests.
